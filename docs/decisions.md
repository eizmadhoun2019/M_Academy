# DECISIONS — Single Decision Register

**Status:** Canonical. This is the only place where deferred decisions live.
**New decisions continue after `D-046`**. D-018…D-022 are retired legacy numbers and are never
reused. ADR numbers 15–22 are reserved legacy numbers (`docs/adr/README.md`).
**Last updated:** 2026-11-25
**Owner of this file:** Project owner (decisions cannot be closed by the agent alone).

## How to use
- Every decision has exactly one ID here. `STATUS.md` does not list decisions; it links here.
- **Status values:** `Open` (blocks the named task) · `Defaulted` (build proceeds on the
  documented default; the owner may override before the named gate) · `Confirmed` (owner
  decided, value recorded) · `Deferred` (explicitly out of H1.5/H2 timing) · `Superseded`
  (replaced; successor named; kept for history) · `Retired` (number no longer used).
- A decision that changes scope, architecture, security boundary or a contract needs owner
  confirmation (`RULES.md` → Change approval). Routine execution choices do not.
- Never delete a row. Change its status and add the successor.
